# KidsTutor 10문제 세션·화면·음량 개선

## 목적

- 모든 학습을 10문제 단위 세션으로 종료한다.
- CoreS3/Core2의 320×240 화면에서 긴 문제와 보기가 하단 조작부에 겹치지 않게 한다.
- 보기 수와 로컬 오디오 음량을 어린이 사용에 맞게 줄인다.

## 동작

- 데일리는 10문제 또는 10분 중 먼저 도달하면 종료하고 보고서를 저장한다.
- 데일리 구성은 복습 1, 영어 3, 소마수학 3, 팩토수학 2, 최종복습 1문제다.
- 영어·수학·6세 수학 자유학습도 10문제를 완료하면 메뉴로 돌아간다.
- 모든 문제는 정답을 포함한 보기 3개만 표시한다.
- 문제 화면 하단에 좌우 스와이프 종료 안내를 표시한다.
- KidsTutor WAV/효과음은 기존 고정 음량의 80%로 재생한다.

## 확인

- CoreS3/Core2 Realtime 빌드
- Core2의 KidsTutor 헤더 탐색과 M5Unified 0.2.7 I2C API 호환
- 긴 한글·영문 문제 및 보기 줄바꿈/말줄임
- 10문제 완료와 데일리 10분 제한
- 중간 스와이프 종료 후 Realtime 복귀
- 오디오 재생 후 I2S/mutex 오류 및 재부팅 없음
