# KidsTutor 밤 시간 화면 밝기

## 목적

밤 시간대에도 KidsTutor가 켜지면 LCD를 낮 밝기로 유지한다. 공부를 끝내면 밤 모드 밝기로 되돌린다.

## 변경

- `NightMode`에 공부 중 낮 밝기 홀드 플래그를 둔다. `tick()`이 이 플래그가 켜진 동안 `nightBrightness`/`display off`를 적용하지 않는다.
- `KidsTutorMod::init()`에서 홀드를 켜고 즉시 낮 밝기를 적용한다. `pause()`에서 해제한다.

## 확인

- 밤(또는 강제 취침)에서 공부 시작 → 화면이 밝아진다.
- 공부 중 10초 이상 두어도 다시 어두워지지 않는다.
- 나가기/스와이프로 챗봇 복귀 후 밤이면 다시 어두워진다.
