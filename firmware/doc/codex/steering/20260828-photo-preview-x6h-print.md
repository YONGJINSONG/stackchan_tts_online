# 사진 프리뷰 버튼 (저장만)

## 목적

`사진 찍자` 후 3-2-1 촬영 → LCD 프리뷰에서 저장하기/저장안함. X6H 인쇄는 쓰지 않는다.

## 동작

- 캡처는 `/app/AiStackChanEx/photo/.preview.jpg`에 둔다.
- 저장하기: 타임스탬프 이름으로 옮긴다. 저장안함 또는 연결 종료: 임시 파일을 지우고 아바타 렌더 일시정지를 해제한다.
- 터치 오버레이 중에는 Realtime 녹음 토글과 모드 스와이프를 막는다.
- `take_photo` function_call_output은 저장 선택이 끝난 뒤에만 보낸다.
